# 🎬 NLP Sentiment Analysis

A Machine Learning based *Sentiment Analysis* project that classifies movie reviews as *Positive* or *Negative* using Natural Language Processing (NLP).

The project uses *TF-IDF* for text feature extraction and compares three different Machine Learning models:

- Logistic Regression
- Naive Bayes
- Linear SVM

A Streamlit web application is also included for real-time sentiment prediction.

---

## 📌 Project Overview

The goal of this project is to analyze the sentiment of a movie review and classify it into:

- 🟢 Positive
- 🔴 Negative

The complete workflow includes:

1. Data Loading
2. Data Cleaning
3. Text Preprocessing
4. Exploratory Data Analysis
5. TF-IDF Feature Extraction
6. Model Training
7. Model Evaluation
8. Model Comparison
9. Confusion Matrix Analysis
10. Model Saving using Pickle
11. Streamlit Deployment
